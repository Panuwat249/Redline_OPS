# Redline OPS

แดชบอร์ดเว็บแบบ static สำหรับติดตามผลการเดินรถ **ระบบรถไฟฟ้าชานเมืองสายสีแดง** (บริษัท รถไฟฟ้า ร.ฟ.ท. จำกัด)
ฝ่ายควบคุมการเดินรถ · ส่วนวางแผนและวิเคราะห์การปฏิบัติการเดินรถ

ไม่ต้องมี server หรือฐานข้อมูล ใช้แค่ HTML + CSS + JavaScript อ่านข้อมูลจากไฟล์ Excel ในโฟลเดอร์ `data/` แล้ววาดกราฟในเบราว์เซอร์ (ใช้ GitHub Pages ได้ทันที)

| หน้า | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| ประสิทธิภาพการเดินรถ | `index.html` | ตรงต่อเวลา, ความเชื่อถือได้, ความพร้อมให้บริการ, เที่ยววิ่ง, ระยะทาง, เที่ยวที่ยกเลิก แยกสายเหนือ / สายตะวันตก / รวม |
| ต้นทุนการเดินรถ | `cost.html` | ต้นทุนรวม โครงสร้างต้นทุน ต้นทุนต่อหน่วย รายได้เทียบต้นทุน รายการที่ใช้เงินมาก/เปลี่ยนมาก |

ทั้งสองหน้ามี **ปุ่มสลับโหมดสว่าง/มืด** (มุมขวาบน) **ปุ่ม "ปรับแต่งกราฟ"** บนทุกกราฟ และ **ปุ่ม "?"** มุมขวาบนของทุกการ์ดที่เปิดคำอธิบายความหมายของกราฟ รองรับทั้งคอมพิวเตอร์และมือถือ

## วิธีเปิดดู

เบราว์เซอร์บล็อกการอ่านไฟล์ Excel เมื่อเปิดแบบ `file://` ดังนั้นต้องเปิดผ่านเว็บเซิร์ฟเวอร์อย่างใดอย่างหนึ่ง

1. **VS Code Live Server** – คลิกขวาที่ `index.html` > Open with Live Server
2. **GitHub Pages** – Settings > Pages > Source: `main` / root จากนั้นเปิดลิงก์ที่ GitHub ให้
3. คำสั่งในเครื่อง: `python -m http.server 8000` แล้วเปิด `http://localhost:8000`

ต้องต่ออินเทอร์เน็ตด้วย เพราะโหลดฟอนต์ Sarabun และไลบรารี (Chart.js, SheetJS) จาก CDN

## ไฟล์ข้อมูลใน `data/`

### `ops-data.xlsx` – ชีต `Stats` (1 แถว = 1 เดือน)

| คอลัมน์ | ความหมาย |
|---|---|
| `Id` | รหัสเดือน รูปแบบ `ปี ค.ศ.-เดือน` เช่น `2021-08` |
| `Month` | ชื่อเดือนภาษาไทย เช่น `สิงหาคม 2564` |
| `TSP5_*` | ความตรงต่อเวลา (ล่าช้าไม่เกิน 5 นาที) % |
| `TSP10_*` | ความตรงต่อเวลา (ล่าช้าไม่เกิน 10 นาที) % |
| `TSA_*` | ความเชื่อถือได้ของการให้บริการ % |
| `TA_*` | ความพร้อมให้บริการของขบวนรถ % |
| `Trips_*` | จำนวนเที่ยววิ่ง |
| `Dist_*` | ระยะทางวิ่ง (กม.) |
| `Cancel_*` | จำนวนเที่ยวที่ยกเลิก |

ทุกกลุ่มมี 3 คอลัมน์: `_N` = สายเหนือ (สีแดงเข้ม) · `_W` = สายตะวันตก (สีแดงอ่อน) · `_Total` = รวม 2 สาย
ชื่อหัวคอลัมน์ไม่สนตัวพิมพ์/ขีดล่าง/เว้นวรรค (`TSP5_N`, `tsp5 n` ใช้ได้เหมือนกัน) และยังรองรับชื่อเก่า เช่น `P5North`

### `cost-data.xlsx` (หน้า cost ใช้ 2 ชีตนี้)

**`dashboard_cost`** – สรุปรายปีงบประมาณ (1 แถว = 1 ปี)

| คอลัมน์ | ความหมาย | หน่วย |
|---|---|---|
| `FiscalYear` | ปีงบประมาณ (พ.ศ.) | – |
| `StaffCost` | ค่าใช้จ่ายด้านบุคลากร | บาท |
| `EnergyCost` | ค่าพลังงาน (ไฟฟ้าขับเคลื่อน/อาคารสถานี) | บาท |
| `MaintenanceCost` | ค่าซ่อมบำรุง | บาท |
| `IndirectCost` | ค่าใช้จ่ายทางอ้อม | บาท |
| `TotalCost` | รวม 4 หมวด | บาท |
| `CarKm` | ระยะทางวิ่งรวมของตู้รถ (Car-Km) | ตู้-กม. |
| `Passenger` | จำนวนผู้โดยสาร | คน |
| `AvgFare` | ค่าโดยสารเฉลี่ย | บาท/คน |
| `CostPerCarKm`, `CostPerPassenger` | ต้นทุนต่อหน่วย (เว็บคำนวณเองจากค่าข้างบน) | บาท |

**`dashboard_cost_detail`** – รายการต้นทุนเชิงลึก (ใช้ในส่วน "เจาะลึกรายการต้นทุน")

| คอลัมน์ | ความหมาย |
|---|---|
| `FiscalYear` | ปีงบประมาณ |
| `CostGroup` | หมวด: `Staff`, `Energy`, `Maintenance`, `Indirect` |
| `CostItem` | ชื่อรายการ |
| `Amount` | จำนวนเงิน (บาท) |

> ปีที่ยังไม่มีข้อมูลต้นทุน (เช่น ปีงบประมาณปัจจุบันที่กรอกแค่ Car-Km) จะไม่ถูกนับในกราฟ
> และหน้าเว็บจะมีข้อความแจ้งว่า "รอข้อมูล" ให้เอง

## วิธีเพิ่มข้อมูลใหม่

**เพิ่มเดือนใหม่ (หน้า index)**
เปิด `data/ops-data.xlsx` > ชีต `Stats` > เพิ่มแถวใหม่ต่อท้าย กรอกให้ครบทุกคอลัมน์ > บันทึก > commit ขึ้น GitHub

**เพิ่มปีงบประมาณใหม่ (หน้า cost)**
1. ชีต `dashboard_cost` – เพิ่ม/แก้แถวของปีนั้นให้ครบ (ยอดแต่ละหมวด, `TotalCost`, `CarKm`, `Passenger`, `AvgFare`)
2. ชีต `dashboard_cost_detail` – เพิ่มรายการย่อยของปีนั้น (`FiscalYear, CostGroup, CostItem, Amount`)
3. บันทึกไฟล์ แล้ว commit ขึ้น GitHub – หน้าเว็บอัปเดตเอง ไม่ต้องแก้โค้ด

ควรให้ชื่อ `CostItem` ตรงกันในทุกปี เพื่อให้ส่วน "เปลี่ยนแปลงมากที่สุด" เทียบข้ามปีได้ถูกต้อง

## ฟีเจอร์ที่ใช้ร่วมกัน

### โหมดสว่าง / มืด
กดปุ่มพระจันทร์/พระอาทิตย์มุมขวาบน ระบบจำค่าที่เลือกไว้ในเครื่อง ถ้ายังไม่เคยเลือกจะตามโหมดของอุปกรณ์ กราฟจะวาดใหม่ให้เข้ากับสีของธีมอัตโนมัติ
การส่งออก PDF ของหน้า index จะสลับเป็นโหมดสว่างชั่วคราวเสมอเพื่อให้พิมพ์อ่านง่าย

### ปรับแต่งกราฟ
กดปุ่ม **ปรับแต่งกราฟ** ที่มุมของกราฟ แล้วเลือกได้ว่า:
- ชนิดกราฟ – แท่ง / เส้น / พื้นที่ (กราฟสัดส่วนเลือกโดนัท / วงกลม)
- สีของแต่ละชุดข้อมูล (ช่องเลือกสี) หรือเลือกชุดสีสำเร็จรูป
- แสดง/ซ่อนตัวเลขบนกราฟ · เส้นกริด · คำอธิบายกราฟ · เส้นโค้งนุ่ม · ซ้อนแท่ง (เฉพาะกราฟที่รองรับ)
- ปุ่ม **ดาวน์โหลดรูป PNG** บันทึกกราฟเป็นรูปภาพ

จุดแดงบนปุ่มแปลว่ากราฟนั้นถูกปรับแต่งอยู่ ค่าที่ตั้งไว้จะถูกจำในเบราว์เซอร์ (localStorage คีย์ `redline-chart-prefs-v1`) ปุ่ม "คืนค่าเริ่มต้น" ใช้ล้างการตั้งค่า
บนมือถือแผงนี้จะเลื่อนขึ้นมาจากด้านล่างของจอ

### ปุ่ม "?" อธิบายความหมายของกราฟ
มุมขวาบนของทุกการ์ด (รวม 27 การ์ด: index 15, cost 12) มีปุ่ม **?** กดแล้วเปิดหน้าต่างที่อธิบายว่า
- **แสดงอะไร** และมีภาพประกอบจำลองให้เห็นรูปแบบกราฟ
- **ลองนึกภาพ** เปรียบเทียบกับเรื่องใกล้ตัว
- **อ่านยังไง** ทีละข้อ (แกน สี เส้นประ ตัวเลข)
- **นำไปใช้ตัดสินใจ** ว่าแบบไหนคือดี แบบไหนควรจับตา และสูตรคำนวณ

ปิดได้ด้วยปุ่ม ✕ กดพื้นที่ว่าง หรือกด Esc บนมือถือจะเลื่อนขึ้นมาจากด้านล่างจอ

**แก้ข้อความหรือเพิ่มการ์ดใหม่:** ข้อความทั้งหมดอยู่ในอ็อบเจกต์ `CONTENT` ของ `js/chart-info.js` (หัวข้อ, คำอธิบาย, วิธีอ่าน ฯลฯ) ถ้าเพิ่มการ์ดใหม่ ให้ใส่ `data-info="รหัส"` ที่แท็กการ์ดใน HTML แล้วเพิ่มรหัสนั้นใน `CONTENT` ปุ่มจะถูกสร้างให้เอง

> ข้อความอธิบายตัวชี้วัด TSA และ TA เขียนตามความหมายทั่วไป ควรให้ทีมตรวจเทียบกับนิยามในสัญญา/คู่มือของบริษัทอีกครั้ง

### รองรับมือถือ
- จอ ≤ 1000px / 760px / 440px ปรับเลย์เอาต์เป็นคอลัมน์เดียว
- กราฟบนมือถือใช้ตัวอักษรเล็กลง ลดจำนวนขีดบนแกน และซ่อนตัวเลขบนกราฟที่แน่นเกินไป (เปิดเองได้จากปุ่มปรับแต่ง)

## นิยามตัวชี้วัดในหน้า cost

| ตัวชี้วัด | สูตร |
|---|---|
| ต้นทุนรวม | บุคลากร + พลังงาน + ซ่อมบำรุง + ทางอ้อม |
| ต้นทุนต่อ Car-Km | ต้นทุนรวม ÷ Car-Km |
| ต้นทุนต่อผู้โดยสาร | ต้นทุนรวม ÷ จำนวนผู้โดยสาร |
| รายได้ประมาณการ | ผู้โดยสาร × ค่าโดยสารเฉลี่ย (**เป็นค่าประมาณ ไม่ใช่รายได้จริงทางบัญชี**) |
| คืนทุนจากค่าโดยสาร | รายได้ประมาณการ ÷ ต้นทุนรวม |
| ผู้โดยสารจุดคุ้มทุน | ต้นทุนรวม ÷ ค่าโดยสารเฉลี่ย |
| ดัชนีเทียบปีแรก | ค่าของปีนั้น ÷ ค่าของปีแรกที่เลือก × 100 (ปีแรก = 100) |

KPI ด้านบนเทียบ **ปีล่าสุดในช่วงที่เลือก** กับปีก่อนหน้า ข้อความสรุปในส่วนหัวของหน้าสร้างอัตโนมัติจากข้อมูล
