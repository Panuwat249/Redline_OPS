# Redline OPS

แดชบอร์ดเว็บแบบ static สำหรับติดตามผลการเดินรถ **ระบบรถไฟฟ้าชานเมืองสายสีแดง** (บริษัท รถไฟฟ้า ร.ฟ.ท. จำกัด)
ฝ่ายควบคุมการเดินรถ · ส่วนวางแผนและวิเคราะห์การปฏิบัติการเดินรถ

ไม่ต้องมี server หรือฐานข้อมูล ใช้แค่ HTML + CSS + JavaScript อ่านข้อมูลจากไฟล์ Excel ในโฟลเดอร์ `data/` แล้ววาดกราฟในเบราว์เซอร์ (ใช้ GitHub Pages ได้ทันที)

| หน้า | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| ประสิทธิภาพการเดินรถ | `index.html` | ตรงต่อเวลา, ความเชื่อถือได้, ความพร้อมให้บริการ, เที่ยววิ่ง, ระยะทาง, เที่ยวที่ยกเลิก แยกสายเหนือ / สายตะวันตก / รวม |
| ต้นทุนการเดินรถ | `cost.html` | ต้นทุนรวม + ต้นทุนต่อตู้-กม. (แท่ง+เส้น) โครงสร้างต้นทุน รายได้เทียบต้นทุน **ผู้โดยสารจริงเทียบกับที่ต้องการ (คน/วัน) แยกสายเหนือ / สายตะวันตก** **กราฟอิสระ** (เลือกข้อมูลจาก Excel ได้ทุกคอลัมน์) รายการที่ใช้เงินมาก/เปลี่ยนมาก |

ทั้งสองหน้ามี **ปุ่มสลับโหมดสว่าง/มืด** (มุมขวาบน) **ปุ่ม "ปรับแต่งกราฟ"** บนทุกกราฟ และ **ปุ่ม "?"** มุมขวาบนของทุกการ์ดที่เปิดคำอธิบายความหมายของกราฟ รองรับทั้งคอมพิวเตอร์และมือถือ

## วิธีเปิดดู

เบราว์เซอร์บล็อกการอ่านไฟล์ Excel เมื่อเปิดแบบ `file://` ดังนั้นต้องเปิดผ่านเว็บเซิร์ฟเวอร์อย่างใดอย่างหนึ่ง

1. **VS Code Live Server** – คลิกขวาที่ `index.html` > Open with Live Server
2. **GitHub Pages** – Settings > Pages > Source: `main` / root จากนั้นเปิดลิงก์ที่ GitHub ให้
3. คำสั่งในเครื่อง: `python -m http.server 8000` แล้วเปิด `http://localhost:8000`

ต้องต่ออินเทอร์เน็ตด้วย เพราะโหลดฟอนต์ Sarabun และไลบรารี (Chart.js, SheetJS) จาก CDN

## ไฟล์ข้อมูลใน `data/`

### `ops-data.xlsx` – ชีต `Stats` (1 แถว = 1 เดือน)

| คอลัมน์ | ความหมาย |
|---|---|
| `Id` | รหัสเดือน รูปแบบ `ปี ค.ศ.-เดือน` เช่น `2021-08` |
| `Month` | ชื่อเดือนภาษาไทย เช่น `สิงหาคม 2564` |
| `TSP5_*` | ความตรงต่อเวลา (ล่าช้าไม่เกิน 5 นาที) % |
| `TSP10_*` | ความตรงต่อเวลา (ล่าช้าไม่เกิน 10 นาที) % |
| `TSA_*` | ความเชื่อถือได้ของการให้บริการ % |
| `TA_*` | ความพร้อมให้บริการของขบวนรถ % |
| `Trips_*` | จำนวนเที่ยววิ่ง |
| `Dist_*` | ระยะทางวิ่ง (กม.) |
| `Cancel_*` | จำนวนเที่ยวที่ยกเลิก |

ทุกกลุ่มมี 3 คอลัมน์: `_N` = สายเหนือ (สีแดงเข้ม) · `_W` = สายตะวันตก (สีแดงอ่อน) · `_Total` = รวม 2 สาย
ชื่อหัวคอลัมน์ไม่สนตัวพิมพ์/ขีดล่าง/เว้นวรรค (`TSP5_N`, `tsp5 n` ใช้ได้เหมือนกัน) และยังรองรับชื่อเก่า เช่น `P5North`

| คอลัมน์ | ความหมาย | หน่วย |

| `MaintenanceCost` | ค่าซ่อมบำรุง | บาท |
| `IndirectCost` | ค่าใช้จ่ายทางอ้อม | บาท |
| `TotalCost` | รวม 4 หมวด | บาท |
| `CarKm` | ระยะทางวิ่งรวมของตู้รถ (Car-Km) | ตู้-กม. |
| `Passenger` | จำนวนผู้โดยสาร | คน |
| `AvgFare` | ค่าโดยสารเฉลี่ย | บาท/คน |

| `CostPerTrip_North` | ต้นทุนต่อเที่ยว สายเหนือ (North Line 22.45 กม.) | บาท/เที่ยว |
| `CostPerTrip_West` | ต้นทุนต่อเที่ยว สายตะวันตก (West Line 14.54 กม.) | บาท/เที่ยว |

**`dashboard_cost_detail`** – รายการต้นทุนเชิงลึก (ใช้ในส่วน "เจาะลึกรายการต้นทุน")

| คอลัมน์ | ความหมาย |
|---|---|
| `FiscalYear` | ปีงบประมาณ |
| `CostGroup` | หมวด: `Staff`, `Energy`, `Maintenance`, `Indirect` |
| `CostItem` | ชื่อรายการ |
| `Amount` | จำนวนเงิน (บาท) |

> ปีที่ยังไม่มีข้อมูลต้นทุน (เช่น ปีงบประมาณปัจจุบันที่กรอกแค่ Car-Km) จะไม่ถูกนับในกราฟ
> และหน้าเว็บจะมีข้อความแจ้งว่า "รอข้อมูล" ให้เอง

## วิธีเพิ่มข้อมูลใหม่

**เพิ่มเดือนใหม่ (หน้า index)**
เปิด `data/ops-data.xlsx` > ชีต `Stats` > เพิ่มแถวใหม่ต่อท้าย กรอกให้ครบทุกคอลัมน์ > บันทึก > commit ขึ้น GitHub

**เพิ่มปีงบประมาณใหม่ (หน้า cost)**
1. ชีต `dashboard_cost` – เพิ่ม/แก้แถวของปีนั้นให้ครบ (ยอดแต่ละหมวด, `TotalCost`, `CarKm`, `Passenger`, `AvgFare`)
2. ชีต `dashboard_cost_detail` – เพิ่มรายการย่อยของปีนั้น (`FiscalYear, CostGroup, CostItem, Amount`)
3. บันทึกไฟล์ แล้ว commit ขึ้น GitHub – หน้าเว็บอัปเดตเอง ไม่ต้องแก้โค้ด

ควรให้ชื่อ `CostItem` ตรงกันในทุกปี เพื่อให้ส่วน "เปลี่ยนแปลงมากที่สุด" เทียบข้ามปีได้ถูกต้อง

## ฟีเจอร์ที่ใช้ร่วมกัน

### โหมดสว่าง / มืด
กดปุ่มพระจันทร์/พระอาทิตย์มุมขวาบน ระบบจำค่าที่เลือกไว้ในเครื่อง ถ้ายังไม่เคยเลือกจะตามโหมดของอุปกรณ์ กราฟจะวาดใหม่ให้เข้ากับสีของธีมอัตโนมัติ
การส่งออก PDF ของหน้า index จะสลับเป็นโหมดสว่างชั่วคราวเสมอเพื่อให้พิมพ์อ่านง่าย

### ปรับแต่งกราฟ
กดปุ่ม **ปรับแต่งกราฟ** ที่มุมของกราฟ แล้วเลือกได้ว่า:
- ชนิดกราฟ – แท่ง / เส้น / พื้นที่ (กราฟสัดส่วนเลือกโดนัท / วงกลม)
- **ชนิดแยกตามชุดข้อมูล** – ถ้ากราฟมีข้อมูลหลายชุด เลือกได้ว่าชุดไหนเป็นแท่ง ชุดไหนเป็นเส้น/พื้นที่ (กราฟผสม) และเลือกแกนซ้าย/ขวาให้แต่ละชุดได้ในกราฟที่รองรับ
- สีของแต่ละชุดข้อมูล (ช่องเลือกสี) หรือเลือกชุดสีสำเร็จรูป
- แสดง/ซ่อนตัวเลขบนกราฟ · เส้นกริด · คำอธิบายกราฟ · เส้นโค้งนุ่ม · ซ้อนแท่ง (เฉพาะกราฟที่รองรับ)
- **ทศนิยม** – เลือกจำนวนทศนิยมของตัวเลขบนกราฟและทูลทิป ทั้งกราฟหรือแยกรายชุดข้อมูล: ตามเดิม / 0 / 1 / 2 / 3 ตำแหน่ง ปัดตามหลักคณิตศาสตร์ (ตั้งแต่ .5 ขึ้นไปปัดขึ้น น้อยกว่า .5 ปัดลง เช่น 744.5 → 745, 744.4 → 744) หน่วยท้ายตัวเลข เช่น % หรือ บาท ยังคงอยู่
- **ลำดับข้อมูล** – ในกราฟที่มีหลายชุดข้อมูล ใต้ชื่อแต่ละชุดมีปุ่ม "▲ ขึ้นก่อน / ▼ ไปหลัง" ลำดับนี้กำหนดว่าแท่งไหนอยู่ซ้ายสุด/ล่างสุดในแท่งซ้อน และลำดับในคำอธิบายกราฟ/ทูลทิป
- **ความกว้างรายการด้านขวา** (180–900px, เฉพาะการ์ด "สัดส่วนต้นทุนแต่ละหมวด") ลดให้ตัวเลข % ชิดชื่อหมวด หรือเพิ่มให้ยืดออก
- **ความกว้างกราฟ** (40–100%) หดกราฟให้แคบลงและจัดกลางการ์ด · **ความกว้างแท่ง / ความกว้างกลุ่มแท่ง** ปรับให้แท่งหนาหรือชิดกันได้ (เฉพาะกราฟที่มีแท่ง)
- **ตำแหน่งตัวเลขแยกรายข้อมูล** – ในกราฟที่มีหลายชุดข้อมูล ใต้ชื่อแต่ละชุดมีแถว "ตัวเลข" เลือกได้ว่าชุดนั้นจะ บน / กลาง / ล่าง / ลูกศรชี้ (หรือ "ตามกราฟ" = ใช้ค่าของทั้งกราฟ) การกดเลือกตำแหน่งของทั้งกราฟจะล้างค่าที่เลือกแยกไว้
- **ตำแหน่งตัวเลข** – อัตโนมัติ / บน / กลาง / ล่าง / ลูกศรชี้ (กราฟโดนัทเลือก ในวง / นอกวง / ลูกศรชี้) ระบบจัดให้ไม่ทับกันเอง ถ้าที่ไม่พอจะย้ายออกไปข้างนอกพร้อมลูกศรชี้กลับมาที่ข้อมูลนั้น การเลือกตำแหน่งจะเปิดตัวเลขให้อัตโนมัติ
- ปุ่ม **ดาวน์โหลดรูป PNG** บันทึกกราฟเป็นรูปภาพ

จุดแดงบนปุ่มแปลว่ากราฟนั้นถูกปรับแต่งอยู่ ค่าที่ตั้งไว้จะถูกจำในเบราว์เซอร์ (localStorage คีย์ `redline-chart-prefs-v1`) ปุ่ม "คืนค่าเริ่มต้น" ใช้ล้างการตั้งค่า
บนมือถือแผงนี้จะเลื่อนขึ้นมาจากด้านล่างของจอ

### ปรับแต่งตารางสรุป (หน้า cost)
ปุ่ม **ปรับแต่งตาราง** มุมขวาบนของการ์ด "ตารางสรุปรายปีงบประมาณ" (ไฟล์ `js/table-tools.js` + `css/table-tools.css`) ค่าที่ตั้งจำในเบราว์เซอร์ (localStorage คีย์ `redline-table-prefs-v1`) ปุ่ม "คืนค่าเริ่มต้น" ล้างทั้งหมด
- **ชุดตามตารางตัวอย่าง** – ปุ่มเดียวจัดตารางให้เหมือนตารางต้นแบบ (ปีงบ · Car.Km · บาท/ตู้/กม. · North/West Line · จำนวนผู้โดยสารจริง · คน/วัน · รายได้ · ต้นทุน/คน (1) · ค่าโดยสารเฉลี่ยต่อคน (2) · ผลต่าง · จุดคุ้มทุน) ธีมแดง-ทอง ปรับต่อได้ทุกอย่าง
- **จุดคุ้มทุน (Break Even Point)** – หัวกลุ่มทอง 3 ช่อง คนต่อปี = ต้นทุนรวม ÷ ค่าโดยสารเฉลี่ยต่อคน · คนต่อเดือน = ÷ 12 · คนต่อวัน = ÷ 360 เลือก ปิด / แค่คนต่อวัน / ทั้งหมด หรือเปิดทีละช่อง
- **ผู้โดยสาร (คน/วัน)** = Passenger ÷ 360 · **ผลต่าง ต้นทุน/คน** = ต้นทุน/คน (1) − ค่าโดยสารเฉลี่ยต่อคน (2) · แถว "เฉลี่ย" = ค่าเฉลี่ยของตัวเลขรายปีในคอลัมน์นั้น
- **คอลัมน์** – ติ๊กแสดง/ซ่อน และ ▲▼ เลื่อนลำดับ มีคอลัมน์ผู้โดยสารรายวัน (รวม/สายเหนือ/สายตะวันตก ทั้งจริงและเป้า) ซ่อนไว้ให้เปิดเพิ่มได้
- **ทศนิยม** – ตั้งทั้งตารางหรือรายคอลัมน์ (0–3) ปัดตามหลักคณิตศาสตร์ (.5 ขึ้นไปปัดขึ้น)
- **หน่วย** – เงิน: บาท / พันบาท / ล้านบาท · จำนวน (Car-Km, ผู้โดยสาร): เต็ม / พัน / ล้าน ตั้งทั้งตารางหรือรายคอลัมน์ หน่วยแสดงใต้ชื่อคอลัมน์
- **% เพิ่ม/ลด จากปีก่อน** – เปิดต่อท้ายคอลัมน์ไหนก็ได้ (หรือเปิด/ปิดทุกคอลัมน์) เลือกทศนิยมของ % รูปแบบป้ายมนหรือตัวอักษร และเปิด/ปิดสีเขียว-แดง
- **ป้ายสีหลังชื่อคอลัมน์** – ขอบมน ใช้สีหมวดเดียวกับกราฟ หรือเลือกสีเองรายคอลัมน์ · เปลี่ยนชื่อหัวคอลัมน์ได้
- **สีธีมและกรอบตาราง** – เลือกสีธีม (แดง น้ำเงิน เขียว ม่วง ส้ม ชมพู ฟ้าน้ำทะเล เทา หรือเลือกสีเอง) เปลี่ยนหัวตาราง แถบสรุป และกรอบทั้งตาราง · กรอบปรับความหนา 0–6px ลาย (เส้นเรียบ/ประ/จุด/เส้นคู่) และสีกรอบเองได้ · ใช้กับรูป PNG ด้วย
- **รูปแบบ** – ธีม เรียบ / แดงขอบมน / แดง-ทอง (ตามตารางต้นแบบ) · ความโค้งขอบ · เส้นตาราง · ความสูงแถว · แถบสลับสี · ชื่อปี · แถว "รวม" และ "เฉลี่ยต่อปี"
- **โหลดรูป PNG** – ปุ่มมุมขวาบนของการ์ด (และในแผงปรับแต่ง) วาดตารางทั้งตารางตามที่ตั้งไว้เป็นรูปความละเอียดสูง (3–4 เท่า) มีหัวเรื่อง ปีงบประมาณ ได้ทั้งโหมดสว่างและมืด
- ปุ่ม "ส่งออก Excel" ยังออกเป็นบาทเต็มเหมือนเดิม ไม่เปลี่ยนตามการปรับแต่งตาราง

### ผู้โดยสารจริง vs ที่ต้องการ (หน้า cost)
มี 3 การ์ดใต้ "รายได้ค่าโดยสารเทียบกับต้นทุน": **รวม** → **สายเหนือ** → **สายตะวันตก** แต่ละการ์ดแสดงผู้โดยสารเฉลี่ย **คน/วัน** ของแต่ละปีงบประมาณ แท่ง = ผู้โดยสารจริง เส้น = ผู้โดยสารที่ต้องการ พร้อมแถบ "ทำได้กี่ % ของเป้า"
ข้อมูลมาจากชีต `dashboard_cost` 6 คอลัมน์ใหม่ (รวม / สายเหนือ / สายตะวันตก อย่างละ จริง+เป้า) (ดูตารางคอลัมน์ด้านบน) กรอกต่อท้ายตารางเดิม แถวละหนึ่งปีงบประมาณ เช่น

| FiscalYear | … | PaxActualPerDay_North | PaxTargetPerDay_North | PaxActualPerDay_West | PaxTargetPerDay_West | PaxActualPerDay_Total | PaxTargetPerDay_Total |
|---|---|---|---|---|---|---|---|
| 2569 | … | (จริงสายเหนือ) | (เป้าสายเหนือ) | (จริงสายตะวันตก) | (เป้าสายตะวันตก) | (จริงรวม) | (เป้ารวม) |

- ใส่เฉพาะตัวเลข ไม่ต้องมีลูกน้ำหรือหน่วย · ปีไหนเว้นว่างก็ไม่มีจุดของปีนั้น
- ถ้าสายใดยังไม่กรอกเลย การ์ดของสายนั้นจะแสดงข้อความบอกว่าต้องเพิ่มคอลัมน์ไหน
- การ์ดตามช่วงปีงบประมาณที่เลือกด้านบน และปีนั้นต้องมีข้อมูลต้นทุนด้วย (เหมือนทุกการ์ดในหน้า)
- ทั้ง 4 ชุดข้อมูลเลือกไปใช้ในการ์ดกราฟอิสระได้ และถูกรวมในไฟล์ Excel ที่ส่งออก

### กราฟอิสระ (หน้า cost)
การ์ด **กราฟอิสระ** ใช้สร้างกราฟเองจากข้อมูลทุกคอลัมน์ใน Excel (ต้นทุนแต่ละหมวด ผู้โดยสาร ค่าโดยสาร ต้นทุนต่อหน่วย รายได้/อัตราคืนทุนที่คำนวณ และรายการย่อยจาก `dashboard_cost_detail`)
- กด **เพิ่ม / ลบข้อมูล** แล้วติ๊กเลือกได้สูงสุด 12 ชุด หรือกดชุดตัวอย่าง (เช่น ต้นทุนรวม + ผู้โดยสาร)
- ชุดที่หน่วยต่างกันจะแยกแกนซ้าย/ขวาให้เอง ถ้าตัวเลขต่างกันมากให้สลับเป็นโหมด **ดัชนี (ปีแรก = 100)** เพื่อเทียบแนวโน้มได้ชัด
- ปรับชนิด/สี/แกน/ตำแหน่งตัวเลขของแต่ละชุดได้จากปุ่ม "ปรับแต่งกราฟ" เหมือนกราฟอื่น
- รายการที่เลือกถูกจำในเบราว์เซอร์ (localStorage คีย์ `redline-cost-free-v1`)

### ปุ่ม "?" อธิบายความหมายของกราฟ
มุมขวาบนของทุกการ์ด (รวม 29 การ์ด: index 15, cost 14) มีปุ่ม **?** กดแล้วเปิดหน้าต่างที่อธิบายว่า
- **แสดงอะไร** และมีภาพประกอบจำลองให้เห็นรูปแบบกราฟ
- **ลองนึกภาพ** เปรียบเทียบกับเรื่องใกล้ตัว
- **อ่านยังไง** ทีละข้อ (แกน สี เส้นประ ตัวเลข)
- **นำไปใช้ตัดสินใจ** ว่าแบบไหนคือดี แบบไหนควรจับตา และสูตรคำนวณ

ปิดได้ด้วยปุ่ม ✕ กดพื้นที่ว่าง หรือกด Esc บนมือถือจะเลื่อนขึ้นมาจากด้านล่างจอ

**แก้ข้อความหรือเพิ่มการ์ดใหม่:** ข้อความทั้งหมดอยู่ในอ็อบเจกต์ `CONTENT` ของ `js/chart-info.js` (หัวข้อ, คำอธิบาย, วิธีอ่าน ฯลฯ) ถ้าเพิ่มการ์ดใหม่ ให้ใส่ `data-info="รหัส"` ที่แท็กการ์ดใน HTML แล้วเพิ่มรหัสนั้นใน `CONTENT` ปุ่มจะถูกสร้างให้เอง

> ข้อความอธิบายตัวชี้วัด TSA และ TA เขียนตามความหมายทั่วไป ควรให้ทีมตรวจเทียบกับนิยามในสัญญา/คู่มือของบริษัทอีกครั้ง

### รองรับมือถือ
- จอ ≤ 1000px / 760px / 440px ปรับเลย์เอาต์เป็นคอลัมน์เดียว
- กราฟบนมือถือใช้ตัวอักษรเล็กลง ลดจำนวนขีดบนแกน และซ่อนตัวเลขบนกราฟที่แน่นเกินไป (เปิดเองได้จากปุ่มปรับแต่ง)

## นิยามตัวชี้วัดในหน้า cost

| ตัวชี้วัด | สูตร |
|---|---|
| ต้นทุนรวม | บุคลากร + พลังงาน + ซ่อมบำรุง + ทางอ้อม |
| ต้นทุนต่อ Car-Km | ต้นทุนรวม ÷ Car-Km |
| ต้นทุนต่อผู้โดยสาร | ต้นทุนรวม ÷ จำนวนผู้โดยสาร |
| รายได้ประมาณการ | ผู้โดยสาร × ค่าโดยสารเฉลี่ย (**เป็นค่าประมาณ ไม่ใช่รายได้จริงทางบัญชี**) |
| คืนทุนจากค่าโดยสาร | รายได้ประมาณการ ÷ ต้นทุนรวม |
| ผู้โดยสารจุดคุ้มทุน | ต้นทุนรวม ÷ ค่าโดยสารเฉลี่ย |

KPI ด้านบนเทียบ **ปีล่าสุดในช่วงที่เลือก** กับปีก่อนหน้า ข้อความสรุปในส่วนหัวของหน้าสร้างอัตโนมัติจากข้อมูล
